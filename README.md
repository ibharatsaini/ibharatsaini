## 🚀 Featured Project

### ⚙️ Automiq — Workflow Automation Platform

[![Live Demo](https://img.shields.io/badge/Live_Demo-Automiq-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://automiq-workflow.vercel.app/)

**React • TypeScript • Node.js • Express.js • Redis • BullMQ • PostgreSQL • TanStack Query**

A workflow automation platform designed around visual workflow creation, reliable background execution, and multi-tenant organization management.

#### What I built

- 🎨 **Visual workflow builder** supporting webhook and schedule triggers, actions, conditional logic, and execution history
- ⚙️ **Distributed job execution engine** using Redis and BullMQ with background workers and retry mechanisms
- 🏢 **Multi-tenant architecture** with organization-level isolation and role-based permissions
- 🔄 **Fault-tolerant concurrent execution** for scalable workflow processing
- 📡 **Real-time workflow monitoring** with detailed execution logs and retry support
